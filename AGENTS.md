# Petunjuk untuk OpenCode (AGENTS.md)

## Bahasa
- Selalu **berkomunikasi dalam Bahasa Indonesia** dalam semua respons, kecuali diminta lain.
- Kode, nama variabel, dan pesan error tetap dalam bahasa Inggris (standar kode), tetapi penjelasan, komentar, dan ringkasan dalam Bahasa Indonesia.

## Proyek
- Dokumen ini berlaku untuk semua repo yang menggunakan opencode.
- Pola pengembangan: `Model + Factory + FormRequest + Controller + View + Seeder + Test`.
- Sebelum selesai: jalankan formatter/linter proyek, pastikan test hijau.
